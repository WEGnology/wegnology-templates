# EEA : Direct trigger

In this template, the use of connection and disconnection triggers will be demonstrated. The connection trigger is activated when the device connects to the WEGnology platform, and the disconnection trigger occurs when the device disconnects.

## Using the trigger

In the example, the triggers are linked to a counter that increments by 1 when they are triggered. With this, it is possible to detect how many times the device has been connected or disconnected through the variables "deviceConnected" and "deviceDisconnected".

## Setup

  1. Import this template into the WEGnology platform in the Embedded Workflows section.
  2. Deploy the example to the device.
